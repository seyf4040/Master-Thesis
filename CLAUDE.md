## Project Overview

Master's thesis on AI-based content moderation for the [Shareish](https://shareish.org) solidarity platform (ULiège). The thesis evaluates 10 pre-trained models across 8 datasets, with a core argument that **deployability (VRAM, inference speed, energy consumption) must be an explicit evaluation axis alongside accuracy** — models requiring 24GB VRAM are not viable for a small NGO like Shareish.

## Running Experiments

No build step required. Dependencies: PyTorch, HuggingFace Transformers, `datasets`, scikit-learn, pandas, psutil, tqdm.

**Full baseline evaluation (10 models × 8 datasets):**
```bash
python code/run_full_baseline.py \
    --output_dir ~/code/results/full_baseline \
    --datasets all --models all \
    --cache_dir ~/datasets/cache \
    --openai_path ~/datasets/openai/samples-1680.jsonl \
    --toxigen_path ~/datasets/toxigen/toxigen_train.jsonl \
    --reddit_en_path ~/datasets/reddit/balanced/data-en/test-en.csv \
    --reddit_fr_path ~/datasets/reddit/balanced/data-fr/test-fr.csv
```

**Quick test (fast models, small datasets):**
```bash
python code/run_full_baseline.py \
    --datasets hatecheck_fr,hatecheck_en,openai \
    --models detoxify_multilingual,koalaai,citizenlab \
    --output_dir ~/code/results/full_baseline ...
```

**HateCheck functionality breakdown:**
```bash
python code/run_hatecheck_analysis.py \
    --output_dir ~/code/results/hatecheck_analysis \
    --cache_dir ~/datasets/cache --models all --datasets both
```

**Aggregate multi-run statistics (mean ± std):**
```bash
python code/aggregate_runs.py \
    --results_dir ~/code/results/full_baseline --models all --datasets all
```

## SLURM Cluster (Alan)

All scripts in `code/slurm_jobs/`. Submit with `sbatch`, monitor with `squeue -u $USER`.

- `run_full_baseline.sbatch` — Single pass, `a5000` partition, 7-day limit
- `run_full_baseline_multi.sbatch` — 3 runs for statistics, 14-day limit
- `run_hatecheck_analysis.sbatch` — HateCheck EN + FR, 12-hour limit
- `run_hatecheck_light.sbatch` — VRAM-filtered subset (1080Ti-compatible models)

Logs go to `~/code/logs/`. Create log dirs before submitting: `mkdir -p ~/code/logs/full_baseline ~/code/logs/hatecheck_analysis`.

## Code Architecture

**Main evaluation loop** (`run_full_baseline.py`, `run_hatecheck_analysis.py`):
- Loads each HuggingFace model → batches samples through it → computes classification metrics (Acc, P, R, F1, TPR, FPR, TNR, FNR) + deployability metrics (avg_inference_ms, gpu_memory_mb, energy_kwh, co2_kg)
- **Checkpointing**: skips already-completed (model, dataset) pairs — safe to interrupt and resubmit
- **VRAM guard**: skips models that won't fit in available GPU memory with a warning
- Results saved as JSON per (model, dataset) pair, then summarized in `summary.txt` / `summary.json`

**10 evaluated models:**
- Lightweight: `detoxify_multilingual`, `detoxify_unbiased`, `koalaai`, `ethicaleye`, `citizenlab`
- Large: `llama_guard_1b`, `llama_guard_8b`, `shieldgemma_2b`, `shieldgemma_9b`, `mistral_7b`

**8 datasets:** HateCheck EN/FR, French Hate Superset, ToxiGen, OpenAI moderation, Civil Comments, Reddit EN/FR

**Helper modules:**
- `utils.py` — dataset loading and preprocessing
- `models_prediction_utils.py` — inference helpers for EthicalEye, KoalaAI, CitizenLab

## Key Thesis Context

- **Deployability framing**: Every result analysis should highlight the VRAM/speed/energy trade-off, not just F1
- **Target platform**: Shareish — a small NGO with limited GPU infrastructure
- **Planned architecture**: Two-tier system (Detoxify as fast pre-filter + Llama Guard for edge cases)
- **Roadmap**: Phase 1 (baseline, current) → Phase 2 (LoRA fine-tuning) → Phase 3 (active learning with Shareish data)
- **Threshold**: Default 0.5 for all models; sensitivity analysis planned
